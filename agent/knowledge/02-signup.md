## 报名页的标准结构

1. **首页**：导航栏 + Banner（活动名 + 一句话价值）+ 信息卡片（时间/地点/主办/名额）+ 活动介绍 + 报名按钮
2. **详情页（content）**：日程或流程 + 嘉宾介绍 + 注意事项
3. **报名页（form）**：表单 + 截止倒计时 + 提交按钮
4. **成功页（success）**：确认信息 + 加入群的方式 + 取消报名的办法

报名类活动**必须有倒计时组件**，截止时间是转化率最高的一个信息。

## 报名页信息卡片写什么

固定四行：时间（含星期和时段）、地点（到楼栋和房间号）、主办（全称，别写简称）、名额（写「限 60 人」或「不限」）。
额外可选：费用（免费就写免费，别留空）、联系人。

时间格式统一写「11月8日 周六 19:00-21:00」，不要只写「11月8日」。

## 报名表单的字段优先级

第一梯队（有就用）：姓名、手机号、学院班级。
第二梯队（按需加）：是否需要接送、饮食禁忌、紧急联系人、备注。
第三梯队（能不收就不收）：身份证号、学号、家庭住址。

收身份证号是要单独说明用途的，没这个必要就别收——既增加填写成本，也增加泄露风险。

## 报名截止与名额

- 有名额上限时，截止时间和「满员即止」两个都写，避免有人白填。
- 截止后倒计时变成「报名已截止」，并在按钮下方留联系方式。
- 表单提交后必须跳到成功页，而不是弹个 toast 就没了——用户要一个能截图的凭证。
